# 3'ris

3つのテトリス盤面を同時に操作する、ブラウザ向けの1人用ゲームです。

## ゲーム概要

中央・右・左の3盤面が、1つの入力で連動して動きます。
3盤面のうち、どれか1つでも上まで積み上がるとゲームオーバーです。

各盤面には異なる向き・タイミングでミノが出現するため、3盤面全体を見ながら操作します。

## 遊び方

`index.html` をブラウザで開いてください。

公開サーバーで使用する場合は、`index.html` と `assets` フォルダを同じ階層に配置してください。

## 操作方法

### キーボード

- `←` / `→`: 左右移動
- `↑` / `X`: 右回転
- `Z`: 左回転
- `↓`: ソフトドロップ
- `Space`: ハードドロップ
- `C`: ホールド
- `P`: 一時停止
- `B`: 3列消去ボーナスの使用

### 画面操作

ゲーム画面下部のボタンから、移動・回転・ドロップ・ホールド・一時停止・ボーナス使用などを操作できます。

## 主な機能

- 3盤面連動型のテトリスゲーム
- 日本語 / 英語対応
- キーボード・タッチ操作対応
- ホールド機能
- ライン消去ボーナス
- ハイスコア保存
- 効果音のON / OFF
- ミノの模様表示切替
- ゲーム中のBGM再生
- 盤面の積み上がりに応じたBGM速度変更

## 使用素材・クレジット

### 背景画像

- `assets/3'ris_bg1.png`
- ChatGPT 無料版を使用して生成・作成

### BGM

- `assets/3'ris_bgm1.ogg`
- `assets/3'ris_bgm2.ogg`
- Google Gemini 無料版を使用して生成・作成

各サービスの利用規約および生成物の利用条件を確認したうえで使用しています。

## ファイル構成

```text
3'ris/
├─ index.html
├─ README.md
└─ assets/
   ├─ 3'ris_bg1.png
   ├─ 3'ris_bgm1.ogg
   └─ 3'ris_bgm2.ogg
```

## 注意事項

- 音声が再生されない場合は、ゲーム開始ボタンを押したあとにサウンド設定を確認してください。
- 素材の利用条件や各サービスの規約が変更された場合は、公開前に再確認してください。
