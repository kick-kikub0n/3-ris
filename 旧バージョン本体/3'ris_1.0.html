キーボード: ←→移動 / ↑or Xで回転 / ↓ソフトドロップ / Spaceハードドロップ / Pで一時停止 / Bでボーナス使用
3つの盤面はすべて同じ操作で動きます。1つでも積み上がったら終了です。

3'ris — ルール

  • 中央を基本盤面としたとき、右盤面はピースが90度回転した状態で降ってきます。
  • 左盤面は中央の1つ前のピースが降ってきます（最初の1手は空です）。
  • 3盤面は同じ操作で連動して動きます。どこか1つでも積み上がったら終了。
  • 2盤面同時・3盤面同時でラインを消去するとスコアボーナス。
  • 一定ウェーブごと及び一定スコア到達ごとに3列消去ボーナスを獲得、1個までストック・任意のタイミングで使用できます。
